# Upload Custom Background Images Here

You can upload your custom car/vehicle background images directly into this `public/` or `public/backgrounds/` folder using the AI Studio File Explorer or by uploading them through the chat.

Example file paths when placed in `public/`:
- `public/car-bg.jpg` -> Accessible in the application as `/car-bg.jpg`
- `public/backgrounds/cyber-cockpit.png` -> Accessible in the application as `/backgrounds/cyber-cockpit.png`
